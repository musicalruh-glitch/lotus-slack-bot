Lotus Slack Bot: A simple bot that has commands intiating small quizes, anime triva and quotes, fun facts, among silly jokes! 

The commands available are the following:

/lotus-animequote : random anime quote :O (outputs a random anime quote)

/lotus-catfact : gets a random cat fact (outputs a random cat fact)

/lotus-ping : goes pong 

/lotus-quiz : generates a random quiz

/lotus-joke : get some laughs in (outputs a random joke)

/lotus-animequiz : anime trivia! in favor of nerds (outputs a random anime quiz)
